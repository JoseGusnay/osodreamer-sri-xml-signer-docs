**Automatiza tu facturación electrónica en Ecuador** con una librería robusta para
**generar, firmar, validar y autorizar comprobantes XML** compatibles con el **SRI**.
Ideal para entornos profesionales como **Node.js**, **TypeScript** y **NestJS**.

<CardGrid>
  <Card title="¿Qué hace esta librería?" icon="document">
    - Genera comprobantes XML (facturas)
    - Firma digitalmente con certificados `.p12`
    - Valida con servicios SOAP del SRI
    - Obtiene autorización oficial
  </Card>
  <Card title="¿Por qué usar osodreamer?" icon="approve-check">
    - Compatible con Node.js, TypeScript, NestJS
    - Soporte para CJS y ESM
    - Fácil de integrar en sistemas existentes
    - Diseñada para el ecosistema ecuatoriano
  </Card>
</CardGrid>

## Instalación

Instala la librería con tu gestor de paquetes favorito:

<Tabs syncKey="pkg">
  <TabItem label="npm">
    ```bash
    npm install osodreamer-sri-xml-signer
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add osodreamer-sri-xml-signer
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add osodreamer-sri-xml-signer
    ```
  </TabItem>
</Tabs>

Compatible con **Node.js**, **TypeScript** y **NestJS**. Soporta `CommonJS` y `ESM`.
