Aprende cómo implementar esta librería en un entorno real con Node.js + TypeScript. El
proyecto de ejemplo recorre el flujo completo:

<Steps>

1. **Generación** de XML con la estructura oficial del SRI

2. **Firma digital** con certificados `.p12`

3. **Validación** contra los servicios del SRI

4. **Autorización** final y almacenamiento

</Steps>

rutas listas para guardar tus XML generados, firmados y autorizados.
