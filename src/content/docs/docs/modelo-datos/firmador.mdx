Aprende cómo estructurar los datos necesarios para firmar un comprobante XML de forma
válida y segura con un certificado digital.

## Modelo del firmador

```ts title="SignXmlCommand.ts"
interface SignXmlCommand {
  p12Buffer: Uint8Array;
  password: string;
  xmlBuffer: Uint8Array;
}
```

- `p12Buffer`: Certificado en formato `.p12` como `Uint8Array`
- `password`: Contraseña que protege el certificado
- `xmlBuffer`: XML del comprobante sin firmar en binario

<Aside>
Asegúrate de que el comprobante esté bien formado y cumpla con los requisitos del SRI
antes de firmarlo.
</Aside>

## Respuesta esperada

La función `signXml(cmd: SignXmlCommand)` retorna una promesa con el XML firmado como
`string`.

```ts
const signedXml: string = await signXml(cmd);
```
